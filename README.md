# Mobile App Dev - EXPO Routing

In deze repo zit een voorbeeld van EXPO routing.

In de les gaan we de volgende onderwerpen bespreken, en met deze repo demonstreren:

- Demonstratie: default routing op basis van folders en documenten (File-Based) 
- Uitwerking: Expo-router LINK
- Uitwerking: Expo-router router.navigate()
- Uitwerking: Dynamic routing + SearchParams Hook


## Opbouw

In deze repo vind je twee branches; main & final
- **Main**: 

	Hier vind je het startpunt van de les (non-functioneel voorbeeld)


	Je kan deze branch gebruiken om zelf mee te schrijven tijdens de les.

- **Final**: 
	
	In de final branch zie je het eindpunt met alle bovengenoemde voorbeelden uitgewerkt.
	
	Deze kan je gebruiken als voorbeeld of om tijdens de les mee te lezen.
